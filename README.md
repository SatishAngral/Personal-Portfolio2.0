# Satish Angral - Frontend Developer & Java Enthusiast Portfolio

A modern, responsive, and visually enhanced personal portfolio website built with clean **HTML5**, **CSS3**, and **JavaScript**, featuring a cute cat profile avatar and tailored for frontend web development and Java skills.

---

## 🌟 What's New & Upgraded

- **Color Scheme: Ivory + Forest Green** (Elegant · Calm · Professional):
  - `#F7F5EF` — Pristine warm Ivory background
  - `#E5E1D6` — Warm Stone / soft almond borders & subtle secondary accents
  - `#174C3C` — Signature Forest Green for primary highlights, badges, buttons, and icons
  - `#252820` — Deep Forest Charcoal for crisp text, dark contrast, and dark theme
- **Personalized for Satish Angral**: All titles, headings, about content, project highlights, and contact information customized for Satish.
- **Cute Cat Profile Avatar Card**:
  - High-resolution adorable cat portrait in a sleek rounded glass card.
  - Interactive Easter Egg: clicking the cat triggers a cute "Meow! 🐾💖" dialogue bubble, heart particles, and a soft audio chime.
  - Floating tech badges: `HTML & CSS`, `Java Core`, and `Pixel Perfect`.
- **Targeted Skills & Tech Stack**:
  - **HTML5 & Web Standards**: Semantic HTML, accessibility, SEO, modern form controls.
  - **CSS3 & UI Styling**: Flexbox, CSS Grid, custom properties, glassmorphism, responsive queries, and keyframe animations.
  - **Java Programming**: Core Java, OOP (Inheritance, Polymorphism, Encapsulation), collections, exception handling, data structures.
  - **JavaScript Essentials**: DOM manipulation, interactive widgets, local storage state.
- **Elevated UI & Visuals**:
  - Dynamic ambient background glow orbs (`.ambient-glow`) for depth.
  - Modern glassmorphism cards with subtle border glows on hover.
  - Interactive **One-Click Email Copy** buttons with toast notifications.
  - Dark and Light theme toggle with `localStorage` persistence.
  - Responsive layout optimized for mobile, tablet, and desktop screens.
